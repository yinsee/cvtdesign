# CampervanTours — website redesign

Static, mobile-first redesign of campervantours.com, built with Tailwind CSS and Alpine.js, with a three.js 3D campervan viewer. Published with GitHub Pages.

Pages: `index.html`, `campervans.html`, `van.html`, `routes.html`, `europe.html`, `overseas-visitors.html`, `prices.html`, `contact.html`.

Anything in [square brackets] is placeholder content to replace before launch.
